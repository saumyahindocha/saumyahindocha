# saumyahindocha.vercel.app

My engineering portfolio: Next.js (App Router, static export), Tailwind CSS v4, TypeScript.
Design system: [DESIGN.md](DESIGN.md).

```
npm install
npm run dev        # http://localhost:3000
npm run build      # static site in out/
```

Pushes to the `portfolio` branch deploy to Vercel; other branches get a preview link.
GitHub Actions runs lint, typecheck, tests and build on every push and pull request.
Working rules for future updates: [CLAUDE.md](CLAUDE.md).
